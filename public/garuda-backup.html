Startup and privacy limits

Testing or loading data downloads the roughly 18 MB Nym worker and verifies its onchain hash. Public bootstrap reads and download hosts see your IP; they do not receive your wallet address. The worker runs in a sandbox without wallet keys or page access. You still trust the bootstrap RPC, specifier owner, Nym network and destination RPC. Errors stop private reads; switching to a direct provider always requires your choice.

Direct reads are not anonymous. The selected provider can see your IP address and queried wallet.

What discovery can and cannot prove

Only records still available on Rabdi, published under this release’s pinned Garuda publisher and V1/V2 deployments, can be found. Unpublished, deleted, expired, or omitted orders may be missing. The search reads at most 50 records per schema across both deployments and warns if that limit is reached. Export a file while records are available.

Ethereum status checks cover signatures, order hashes, counters, fills, and deadlines. They do not prove that an order can trade: original publication anchors, transfer history, asset state, and permissions still matter. This tool does not buy or accept bids. Incoming bids name you as the original stake owner; current ownership may have changed.

Arkiv storage expiry is separate from the signed order deadline. The current network allows about 182 days per lifetime, with renewal before expiry; this tool does not promise permanent storage or renew records. Local-file cancellation and counter invalidation work without Arkiv.

This file bundles its interface and Anon-RPC harness; it uses no analytics, hosted fonts or Garuda API. Direct mode needs no remote scripts. Optional Anon-RPC / Nym downloads hash-verified network code into a sandbox and needs a working Nym route. Optional order discovery queries Arkiv directly. The wallet and selected RPC remain trust dependencies; RPC responses are not independently proven. Code hashes are checked against this release before actions. Confirmed transactions and market orders are public. This is position access, not lost-key recovery.
