# Garuda contracts

The [deployed Signature V1 package](deployed-signature-v1/README.md) contains the source, tests, compiler input and Ethereum deployment records for [`0xf8a4719a149227a9a15456a62ac49baa8b95554d`](https://etherscan.io/address/0xf8a4719a149227a9a15456a62ac49baa8b95554d#code).

This contract validates WISE-denominated Signature stake listings and bids through Seaport 1.6. The package includes instructions for rebuilding its source and checking it against live bytecode without a wallet.
